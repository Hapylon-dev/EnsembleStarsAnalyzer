# Ensemble Stars!! Music Tap Timing Analyzer

**『あんさんぶるスターズ！！Music』のライブリザルト画像から、タップタイミングを解析する非公式Webアプリです。**

リザルト画像をアップロードし、楽曲情報と総ノーツ数を入力すると、タップタイミングの分布を推定し、本アプリ独自のスコア・ランク・ランキングを確認できます。

> 本アプリは非公式のファンメイドツールです。Happy Elements株式会社および関連会社とは関係ありません。ゲーム公式の機能・サービスではありません。

## 主な機能

- ライブリザルト画像のアップロードと解析
- タップタイミング棒グラフの検出・判定分布の推定
- Achievement・Precision・Balance・Overall Scoreの算出
- 本アプリ独自の評価Rank・グレード表示
- 解析結果をまとめたリザルトカードの生成
- リザルトカードのPNG保存
- 解析結果のX共有
- 固定基準データと比較する総合評価ランキング
- ランキング順位に応じた称号の表示

各スコア・ランク・ランキングは本アプリ独自の指標です。ゲーム公式の評価やランキングではありません。

## 使い方

1. [Webアプリ](https://ensemble-stars-analyzer.streamlit.app/)を開きます。
2. 対応するライブリザルト画像をアップロードします。
3. 楽曲名・難易度・レベルを入力します。
4. リザルト画面に表示された総ノーツ数を入力します。
5. **「解析開始」** を押します。
6. 解析結果とリザルトカードを確認します。
7. 必要に応じて、リザルトカードを保存したり、解析結果をXで共有したりできます。

## 解析対象の画像

解析対象は、**新ライブUI（2025年4月29日以降）のライブリザルト画面**です。

対応するライブ：
- ライブチャレンジ
- ノーマルライブ
- あんさんぶるライブ
- ソロライブ

画像は次の条件を満たすものを使用してください。

- ゲーム内のライブリザルト画面を撮影したスクリーンショット
- 編集・加工していない画像
- タップタイミング棒グラフが明確に見える画像
- 十分な解像度がある画像
- 対象条件を満たすALL AMAZING相当の結果
- MISSがなく、総ノーツ数と最高判定数が一致している結果

ライブの種類によって対象となるリザルト表示が異なります。ライブチャレンジでは「ALL AMAZING（100.000%）」、その他の対象ライブでは「PERFECT COMBO」が表示されたリザルトを使用してください。

**対応画像形式：** PNG / JPG / JPEG / WebP  
**アップロード上限：** 20MB

条件を満たしていても、画像の解像度や表示状態によって正しく解析できない場合があります。

## 解析結果について

### 判定分布

タップタイミング棒グラフを画像解析し、判定分布を推定します。表示される判定数はゲーム内部の正式な判定データではありません。

### 各種スコア

| 指標 | 内容 |
|---|---|
| Achievement | AMAZING+・AMAZINGをもとに算出する本アプリ独自の達成率 |
| Precision | タップタイミングの中央への集中度 |
| Balance | SLOWとFASTの偏りの少なさ |
| Overall Score | PrecisionとBalanceをもとにした総合評価 |
| Rank | Overall Scoreに応じた本アプリ独自のランク |

Overall Scoreは、Precisionを80%、Balanceを20%として算出します。Balanceを算出できない場合は、アプリの仕様に従って評価を表示します。

### ランキング

固定された基準データと今回の解析結果を比較し、順位や上位率などを表示します。今回の解析結果がランキング基準データへ自動追加される仕組みではありません。

---

## 解析上の注意

本アプリは、リザルト画像に表示された棒グラフを画像解析して値を推定します。そのため、次の点に注意してください。

- 判定分布は推定値であり、ゲーム内部の正式な判定数ではありません。
- Achievement・Precision・Balance・Overall Score・Rankは本アプリ独自の計算結果です。
- ランキングは本アプリ独自の基準データとの比較であり、公式ランキングではありません。
- 総ノーツ数の入力を間違えると、推定判定数やAchievementなどに影響する場合があります。
- 解析結果がゲーム内の表示や内部データと一致することを保証するものではありません。

## よくある質問

### 無料で利用できますか？

現在、無料で利用できます。会員登録も不要です。

### スマートフォンから利用できますか？

はい。スマートフォンのブラウザから利用できます。

### どのような画像でも解析できますか？

いいえ。上記の「解析対象の画像」に記載した条件を満たすリザルト画像を使用してください。

### 解析結果はゲーム公式の数値ですか？

いいえ。画像から推定した値と、本アプリ独自の計算式による評価です。

### ランキングに自分の結果は登録されますか？

解析結果はランキング基準データへ自動追加されません。画面上で基準データと比較して表示します。

### 解析に失敗した場合は？

対応するリザルト画像か、棒グラフが明確に表示されているか、画像を加工していないか、総ノーツ数が正しいかを確認してください。条件を満たしていても解析できない場合があります。

## 開発環境・起動方法

### 主な技術

- Python
- Streamlit
- OpenCV
- Ultralytics YOLO
- PyTorch
- NumPy
- pandas
- Matplotlib

### ローカルでの起動

Python環境を用意し、リポジトリのルートディレクトリで以下を実行します。

```bash
python -m venv .venv
```

Windows PowerShellの場合：

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

YOLOの学習済みモデルとして、設定ファイルで指定された `weights/graph_detector_v13.pt` が必要です。
