# OVERALL PACHINKO 演出・仕様マニュアル

- 対象ビルド：ensemble-stars-analyzer 3.3.3-dev 改修作業版
- 更新日：2026-11-12
- 状態：開発中。演出出現率は暫定調整値。実際のブラウザー・端末でのプレイ確認後に最終確定する。

## 1. 基本方針

演出は抽選結果を変更しない。大当たり判定、保留昇格、出玉振り分けはゲーム処理で決まり、演出専用乱数は画面表示・告知演出の選択だけに使う。

## 2. 通常時

### 演出品質

PREMIUM相当の演出に固定する。演出品質の選択UIは設けない。変動中に演出状況を説明する短文・ラベルは表示せず、色・光・画面効果・音で表現する。

### 通常時演出モード

| モード | 説明 |
|---|---|
| STANDARD | 演出をバランスよく楽しむ王道モード。 |
| FORESHADOW | 演出をじっくり楽しむモード。 |
| QUICK | 変動を短くし、テンポよく楽しむモード。 |

遊タイムは150回転連続未当たりで発動する。残り50回転からカウントダウンを表示し、残り10回転以下では表示を強調する。

## 3. RUSH基本仕様

- 大当たり確率：1/73
- ST本体：116回転
- ST終了時の残保留：最大4個
- 最大抽選回数：116＋4＝120回
- ST本体116回転を消化した後は新しい保留を追加できず、すでに貯まっている保留だけを消化する。
- 残保留がない、または最大4個を消化し終えるとRUSH終了。
- 大当たり時はST116回転に再セット。未消化保留は保留色を保持して次のSTへ持ち越し、当否は消化時に抽選する。
- ST本体のみの理論継続期待度：約79.81%。残保留4個を含む最大120回で約80.89%。

### 保留の追加

HOLDボタン長押しで0.5秒ごとに保留を追加する。画面上の保留表示は最大5個（消化対象1個＋待機中最大4個）。ST116回転を消化した後は追加不可。

## 4. RUSH演出モード

| モード | 説明 |
|---|---|
| STANDARD | 演出をバランスよく楽しむ王道モード。 |
| SHADOW VISITOR | 暗闇に潜む気配と襲来の予兆で、当落の瞬間を楽しむ告知モード。 |
| IMPACT | 強烈な閃光と衝撃で、当落の瞬間を楽しむ一発告知モード。 |
| ONE PUSH | ボタンを押すその瞬間まで結果が分からない、任意タイミング解放モード。 |

SHADOW VISITORとONE PUSHは数字をブラックアウトしてから演出を開始する。IMPACTは数字を暗転させず、閃光・振動を中心に演出する。結果数字は専用演出の後に表示する。

SHADOW VISITOR・IMPACT・ONE PUSHの専用演出（煽りを含む）が発生した場合の大当たり信頼度は、現行設定で40%。専用演出が発生しない大当たりもある。演出の発生率は保留色に応じて調整し、青保留からも発生する。

### 専用告知演出の暫定出現率

| 保留色 | 保留自体の当選信頼度 | 専用告知の出現率 |
|---|---:|---:|
| 青 | 約0.526% | 1.3% |
| 緑 | 3% | 7.4% |
| 赤 | 60% | 9.0% |
| 金 | 85% | 11.5% |
| 虹 | 100% | 対象外（大当たり確定） |

各色で専用演出が発生した場合の大当たり信頼度は40%となるよう、当たり時・外れ時の演出選択率を逆算している。上記出現率は暫定値であり、プレイ確認を踏まえて調整する。現在の保留色構成（青90%、緑9%、赤0.9%、金0.09%、虹0.01%）を用いた専用告知の全体出現率は約1.92735%/保留。

専用効果音はオリジナル合成音とし、専用の長い告知音は大当たり時のみ再生する。既存作品の音源・旋律は使用しない。

## 5. 最終10回転の演出

ST本体の最後10回転（107～116回転目）と、その後の残保留最大4個を合わせた最大14回転を最終局面として扱う。該当区間は消化間隔を長くして緊張感を高める。この区間で大当たりした場合は専用の祝福演出を追加する。残り回転数によって大当たり確率は変化しない。

## 7. リザルトカード

プレイ日時は専用枠内に配置し、枠の下罫線を含めて描画する。称号欄はカードから削除し、PNG保存時に日付や下端が切れない構成にする。総獲得NOTES、RANK、初当たり、RUSH、出玉振り分け、平均出玉、QRコードなどは維持する。
